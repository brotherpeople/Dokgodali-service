## 1. 물건 정보 및 운임 산출 (Step 1)

현행 소형·중형·대형 고정가(€9/16/28) 선택을 **박스별 입력 목록**으로 교체한다.

- 박스 추가·삭제: 최소 1개, 최대 50개 (50개 도달 시 추가 버튼 비활성화)
- 박스별 입력: 가로·세로·높이(cm), 실중량(kg), 캐리어 여부 체크
- 박스별 물품 목록 (행 추가·삭제): 영문명, 브랜드, 색상, 사이즈, 수량, 단가(€), 이미지 URL, 상품 URL
  - 안내 문구: "옷 대신 바지, 티셔츠 등 구체적으로 적어 주세요"
  - 신상품 체크 시 상품 URL 필수
- 청구 중량
  - 치수는 각 변 1cm 단위 올림 후 사용
  - 부피 무게 = 가로 × 세로 × 높이 ÷ 6000
  - 청구 중량 = max(부피 무게, 실중량), 최소 1kg
  - 올림: 30kg 이하 → 0.5kg 단위 (10.2 → 10.5), 30kg 초과 → 1kg 단위 (30.2 → 31)
  - 올림은 부피 무게·실중량·청구 중량 모든 계산에 적용
- 기본 운임: `6.70 + 4.30 × 청구중량` (요금표와 일치, 상수 `RATES.base`로 관리)
- 관부가세 안내: 물품 단가 합계가 일정 금액을 넘으면 "물품가 + 국제운송비가 USD 150 초과 시 관부가세가 부과됩니다" 경고 표시 (환율은 계산하지 않고 안내만)
- 물품 제한 경고 (입력값 기준, 제출은 막지 않음)
  - 건강기능식품(의약품·영양제·기능성 화장품): 박스당 6개 초과 시 폐기 안내
  - 분유: 5kg 초과 시 폐기 안내
  - 주류: 박스당 1L 이하 1병만 면세 안내
  - 구현 방식: 물품 행에 "구분" 선택(일반 / 건강기능식품 / 분유 / 주류) 추가 여부는 결정 필요

## 2. 추가 운임 자동 적용

| 항목 | 조건 | 금액 |
|---|---|---|
| OVER SIZE | 세 변 합 ≥ 140cm 또는 한 변 ≥ 80cm | 박스당 €20 + 부피 무게 30kg 초과분 1kg당 €1 |
| OVER WEIGHT | 실중량 ≥ 20kg | 박스당 €20 + 실중량 30kg 초과분 1kg당 €1 |
| 중복 | OVER SIZE와 OVER WEIGHT 동시 해당 | 각각 합산 |
| 멀티 화물 | 동일 수취인 2박스 이상 | 박스당 €3 |
| 캐리어 | 캐리어 체크된 박스 | €15 |
| 이삿짐 통관 | 이사화물 / 반입 건 선택 | 건당 €30 |
| 보관비 | 입고 후 7일 무료, 8일차부터 박스당 1일 €1 | 신청 시 계산 불가 → **안내 문구만** |

- 안내 문구 추가: "OVER SIZE와 OVER WEIGHT는 각각 합산 청구됩니다. 한국 착불 요금은 없습니다."
- 모든 요율은 스크립트 상단 설정 상수(`RATES`)에서만 관리한다.

## 3. 접수 방식 (Step 2)

- **고정 픽업:** "매주 화요일"만 표기. 시간(17:00–21:00)과 "정해진 순회 경로로만 픽업" 문구 삭제. 요약의 "17:00–21:00 배정"도 삭제
- **접수처 방문:** "보관비" → "접수비" (카드 문구, `methodData.dropoff.condition`, 요약)
- **타지역 픽업 (신규 카드):** 베를린 외 지역. 우편번호·도시명 입력란 (선택 시 필수)
  - 요금 안내: "창고 기준 거리 1km당 €1 (Google 지도 기준), 견적 시 산정"
  - 프랑크푸르트 허브 노선 도시 선택 시: 무료 픽업 기준(인근 €70 / 그 외 €350) 안내
- **공통 안내 (공식 페이지 기준):** 픽업은 예약금 확인 후 진행, 예약금은 최종 결제에서 차감. 차량 접근 가능한 곳에 준비. 실측 후 금액 변동 가능

## 3-1. 공식 페이지와 문구 맞추기

- **위험물 확인 체크 문구** 갱신. 현행 "가스, 인화성 물질, 배터리, 향수, 스프레이, 김치, 한약, 육류, 씨앗"을 공식 목록으로 교체
  - 배터리 전 종류와 배터리 내장 제품 (블루투스 스피커, 시계, 충전식 면도기 등)
  - 향수, 디퓨저, 스프레이, 위험물 표시 제품
  - 김치·장류·한약·즙, 육포·소시지·고기 포함 라면·반려동물 사료와 간식
  - 생과일·생채소·껍질 있는 견과류·씨앗과 곡물 종자
  - 허위 신고 시 당일 전체 화물 보류와 손해배상 청구 가능 안내
- **이삿짐 통관 선택 시 안내:** 서명한 서류(여권 사본, 출입국 기록, 해외 거주 사실 확인서. 가족은 전원)를 info@dokgodali.de로 전송, 중고 물품만 면세. 완료 화면에도 표시
- **보상 규정 동의:** 약관 동의 문구에 보상 규정 요지 추가 (신고가액 기준 보상, 수령 후 14일 이내 청구, 신고 누락·부정확 시 보상 제외). 신고가액 = 물품 단가이므로 단가 입력 필수
- **보관비 안내:** "입고 후 7일 무료, 8일차부터 박스당 1일 €1, 도착 후 60일 경과 화물은 폐기될 수 있음"

## 4. 개인정보 및 기타 옵션 (Step 3)

- **신청인 주소:** 자동완성 적용 (입력 3자 이상, 300ms 디바운스, 독일 한정 결과). 자동완성 실패 시 직접 입력 허용
- **카카오톡 아이디:** 신규 입력란
- **배송지 정보:** 필수 유지 + "미정" 체크. 체크 시 배송지·수취인·통관고유부호 칸 비활성화, 검증 통과
- **결제 방법:** 선택 메뉴 제거 → "계좌이체만 가능합니다. 결제 계좌는 견적서 하단에서 확인하실 수 있습니다." 고정 안내. payload `payment: "계좌이체"`
- **통관 구분 (신규, 필수):** 전자상거래 / 일반통관 라디오
- **SNS 사진·영상 촬영 동의 (신규, 필수):** 네 / 아니오 라디오. "개인을 특정할 수 없는 형태" 문구 포함
- **유입 경로 (신규):** 지인/친구 추천, 인스타그램, 스레드, 페이스북, 네이버 블로그/카페, 인터넷 검색, 기타 (기타 → 직접 입력란)

## 5. 연동 수정

- **배송 요약 (사이드바):** 박스 수, 총 청구 중량, 추가 운임 항목별 내역, 예상 합계
- **전송 payload:** `boxes[]` (치수, 실중량, 부피 무게, 청구 중량, 캐리어, 물품 목록, 박스별 추가 운임), `surcharges`, `pickupRegion` (타지역 우편번호·도시), `kakaoId`, `deliveryUndecided`, `customsType`, `mediaConsent`, `referral`, `referralOther`. `summary` 문자열은 "박스 N개 · 접수 방식 · 날짜"
- **관리자 상세 보기** (`dokgodali-schedule.html` 1376행 부근 delivery 분기): 새 필드 표시. 기존 `cargoes` 형식 신청도 계속 표시 (하위 호환)

## 작업 순서와 검증

1. 계산 로직을 순수 함수로 분리 (`roundWeight`, `volumetricWeight`, `chargeableWeight`, `boxSurcharges`, `orderTotal`)
   → 검증: Node 테스트 스크립트로 10.2 → 10.5, 30.2 → 31, 79.3cm → 80cm(OVER SIZE 진입), 경계값 20kg·30kg·140cm·80cm, OVER SIZE+WEIGHT 중복, 2박스 할증, 요금표 대조(1kg €11.00, 10kg €49.70, 30kg €135.70)
2. Step 1 박스 목록 UI + 물품 목록
   → 검증: 1개 미만 삭제 불가, 50개 초과 추가 불가, 요약 실시간 갱신
3. Step 2 접수 방식 수정·타지역 픽업
   → 검증: 문구 변경 확인, 타지역 선택 시 우편번호·도시 필수
4. Step 3 개인정보 항목
   → 검증: 미정 체크 시 다음 단계 진행, 필수 라디오 미선택 시 오류
5. payload·관리자 상세 보기
   → 검증: 테스트 Supabase에 실제 제출 후 관리자 화면에서 새 신청·예전 신청 모두 정상 표시
6. 375px 모바일 화면 확인
